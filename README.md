# Asset Management System (AMS)

## Overview

The **Asset Management System (AMS)** is a full-stack web application designed to streamline the management 
and tracking of organizational assets throughout their lifecycle. It provides a centralized platform for recording, monitoring, evaluating, and maintaining company assets while improving operational efficiency and data accuracy.

The application supports the complete workflow from 
**Job Order (JO)** creation, 
**Work Order (WO)** generation, 
**asset evaluation**, **expense tracking**, and **status monitoring**, 
making it suitable for organizations that require structured asset maintenance and inventory management.

---

## Features

* 📋 Asset registration and management
* 🔍 Advanced search and filtering
* 📦 Job Order (JO) management
* 🛠️ Work Order (WO) generation
* 💰 Expense tracking and monitoring
* 📊 Asset evaluation workflow
* 📈 Status monitoring and reporting
* 📱 Responsive design for desktop and mobile devices
* 🔒 Secure API communication between frontend and backend
